# Spice Garden: Restaurant Menu Website

A responsive restaurant menu page built with HTML, CSS, Bootstrap and a little JavaScript.

Live demo: https://prasanna2937.github.io/restaurant-menu/

## Features
- Responsive navbar, hero section and Bootstrap card layout
- Veg / Non-Veg filter buttons
- Item details popup (Bootstrap modal)
- Contact form with validation (demo only, no backend)
- Mobile, tablet and laptop friendly

## Built with
HTML5, CSS3, Bootstrap 5, basic JavaScript
